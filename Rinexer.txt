EN:

Rinexer version 1.0.1 is a collection of modules written in Fortran
for reading RINEX 3.x observation files. It is based on the RINEX
version 3.04 specification, which is publicly available in the
rinex304.pdf file, focusing specifically on Table A2 and Table A3.

Modules:
 obs_rinex3_types_mod.f90
 obs_rinex3_indexes_mod.f90
 obs_rinex3_reader_mod.f90
 obs_rinex3_writer_mod.f90

The RINEX file is read (parsed) into data structures defined in the
obs_rinex3_types_mod.f90 module.


SAMPLE PROGRAMS

Example usage is demonstrated in the following programs:

THE RINEX 3.x FORMAT

A RINEX 3.x file consists of a header section and a data section. The
header section is referred to as the header, while the data section is
called the body.

                        ---------------------
                        |                   |
                        |      HEADER       |
                        |                   |
                        ---------------------
                        |                   |
                        |                   |
                        |                   |
                        |       BODY        |
                        |                   |
                        |                   |
                        |                   |
                        ---------------------

The header consists of records identified by labels, such as RINEX
VERSION / TYPE, PGM / RUN BY / DATE, etc.

                        ---------------------
                        |             LABEL |
                        |             LABEL |
                        |             LABEL |
                        ---------------------
                        
The body consists of data records, also known as epoch records, which
contain the observation data.

                        ---------------------
                        | EPOCH RECORD      |
                        | EPOCH RECORD      |
                        | EPOCH RECORD      |
                        | EPOCH RECORD      |
                        | EPOCH RECORD      |
                        | EPOCH RECORD      |
                        | EPOCH RECORD      |
                        ---------------------
                        
To read observation data from epoch records, it is crucial to read
the SYS / # / OBS TYPES labeled lines from the file header.


HOW TO USE IT

The module responsible for reading the RINEX file is
obs_rinex3_reader_mod.f90. It functions as a parser.

General workflow:

1. First, read the file header using the read_header procedure.

2. Allocate memory for any epoch record using the
   allocate_epoch_record procedure.

3. Accessing array elements is done by providing an index. Satellite
   system indexes are predefined in obs_rinex3_indexes_mod.f90.  Use
   the get_sys_index function to retrieve the indexes of the selected
   satellite systems, for example:
   
   i_G = get_sys_index('G')
   i_J = get_sys_index('J')

   Observation indexes are obtained from the SYS / # / OBS TYPES
   records in the file header.  Use the get_obs_index function from
   the obs_rinex3_indexes_mod.f90 module to retrieve the indexes of
   the selected observation types, for example:

   i_gl1c = get_obs_index('G', 'L1C', h%sys_num_obs_types)
   i_jl1c = get_obs_index('J', 'L1C', h%sys_num_obs_types)

4. Read the epoch record using the read_next_epoch_record procedure.

5. Use the retrieved indexes to extract data from the epoch
   record. For example, for an epoch record named "epr":

   associate (A => epr%sats_obs)
     do i_prn = 1, A(i_G)%n_prns
       gl1c_val = A(i_G)%sys_sats_obs(i_gl1c, i_prn)
     end do
     do i_prn = 1, A(i_J)%n_prns
       jl1c_val = A(i_J)%sys_sats_obs(i_jl1c, i_prn)
     end do
   end associate


PRINTING DATA

The parsed data can be printed to the screen or written to a file
using the obs_rinex3_writer_mod.f90 module. The data will be output in
the standard RINEX format.

FORMAT RINEX 3.x

Plik RINEX 3.x składa się z sekcji nagłówka i sekcji danych. Sekcja
nagłówka nazywana jest nagłówkiem, zaś sekcja danych ciałem.

			---------------------
			|                   |
 			|     NAGŁÓWEK      |
			|                   |
			---------------------
			|                   |
			|                   |
			|                   |
			|       CIAŁO       |
			|                   |
			|                   |
			|                   |
			---------------------
				   
Nagłówek składa się z rekordów oznaczonych etykietami np. RINEX
VERSION / TYPE, PGM / RUN BY / DATE itd.

			---------------------
			|          ETYKIETA |
 			|          ETYKIETA |
			|          ETYKIETA |
			---------------------

Ciało składa się z rekordów danych albo inaczej rekordów epok, które
zawierają dane obserwacyjne.

			---------------------
			| REKORD EPOKI      |
			| REKORD EPOKI      |
			| REKORD EPOKI      |
			| REKORD EPOKI      |
			| REKORD EPOKI      |
			| REKORD EPOKI      |
			| REKORD EPOKI      |
			---------------------

Dla odczytania danych obserwacyjnych z rekordów epok kluczowe jest
odczytanie linii z etykietami SYS / # / OBS TYPES z nagłówka pliku.


JAK TEGO UŻYWAĆ

Modułem odpowiedzialnym z odczyt pliku RINEX jest
obs_rinex3_reader_mod.f90. Jest to parser.

Ogólny schemat postępowania:

1. Najpierw należy odczytać nagłówek pliku procedurą read_header.

2. Zaalokować pamięć na dowolny rekord epoki procedurą allocate_epoch_record.

3. Dostęp do elementów tablic następuje przez podanie indeksu.
   Indeksy systemów satelitarnych są na stałe zapisane w
   obs_rinex3_indexes_mod.f90. Przy pomocy funkcji get_sys_index
   należy pobrać indeksy wybranych systemów satelitarnych np.
   
   i_G = get_sys_index('G')
   i_J = get_sys_index('J')

   Indeksy obserwacji uzyskuje się z rekordów SYS / # / OBS TYPES
   nagłówka pliku. Przy pomocy funkcji get_obs_index z modułu
   obs_rinex3_indexes_mod.f90 pobrać indeksy wybranych typów
   obserwacji np.

   i_gl1c = get_obs_index('G', 'L1C', h%sys_num_obs_types)
   i_jl1c = get_obs_index('J', 'L1C', h%sys_num_obs_types)

4. Odczytać rekord epki przy pomocy procedury read_next_epoch_record.

5. Przy pomocy posiadanych indeksów wybrać dane z rekordu epoki np.
   dla rekordu opoki epr
   associate (A => epr%sats_obs)
     do i_prn = 1, A(i_G)%n_prns
       gl1c_val = A(i_G)%sys_sats_obs(i_gl1c, i_prn)
     end do
     do i_prn = 1, A(i_J)%n_prns
       jl1c_val = A(i_J)%sys_sats_obs(i_jl1c, i_prn)
     end do
   end associate

RINEX.
