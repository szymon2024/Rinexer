EN
v1.0.3

obs_rinex3 is a source code Fortran module designed for reading and
writing RINEX 3.x observation files. It requires writing a Fortran
program that will use it.

> ⚠️ **Note:** The current version does not support handling special
events and comments within the observation data.

More information in the `src` folder.



PL
v1.0.3

obs_rinex3 to moduł języka Fortran zaprojektowany do odczytu plików
obserwacyjnych RINEX 3.x. Wymaga napisania programu w Fortranie,
który będzie z niego korzystał.

> ⚠️ **Uwaga:** Obecna wersja nie wspiera obsługi zdarzeń specjalnych
i komentarzy w danych obserwacyjnych.

Więcej informacji w folderze `src`.
