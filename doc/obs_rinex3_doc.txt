EN

obs_rinex3 is a Fortran module for reading and writing RINEX 3.x
observation files. It is based on the RINEX version 3.04
specification, which is publicly available in the rinex304.pdf file,
focusing specifically on Table A2 and Table A3.

Module file obs_rinex3.f90 is in src folder.

Example usages are demonstrated in the following programs:
- obs_rinex3_prog1.f90
- obs_rinex3_prog2.f90
- obs_rinex3_prog3.f90
located in the examples directory.


THE RINEX 3.x FORMAT

A RINEX 3.x file consists of a header section and a data section. The
header section is referred to as the header, while the data section is
called the body.

                        ---------------------
                        |                   |
                        |  HEADER SECTION   |
                        |                   |
                        ---------------------
                        |                   |
                        |                   |
                        |                   |
                        |   DATA SECTION    |
                        |                   |
                        |                   |
                        |                   |
                        ---------------------

The header consists of records identified by labels, such as RINEX
VERSION / TYPE, PGM / RUN BY / DATE, etc.

                        ---------------------
                        |             LABEL |
                        |             LABEL |
                        |             LABEL |
                        ---------------------
                        
The body consists of data records, also known as epoch records, which
contain the observation data.

                        ---------------------
                        | EPOCH RECORD      |
                        | EPOCH RECORD      |
                        | EPOCH RECORD      |
                        | EPOCH RECORD      |
                        | EPOCH RECORD      |
                        | EPOCH RECORD      |
                        | EPOCH RECORD      |
                        ---------------------
                        
Important: To read observation data from epoch records, it is crucial
to read the SYS / # / OBS TYPES labeled lines from the file header.


HOW TO USE THE MODULE IN THE CODE

General workflow of reading RINEX file:

1. Add "use obs_rinex3" at the beginning of your program.

2. First, read the file header using the read_header procedure.

3. Allocate memory for any epoch record using the
   allocate_epoch_record_buffer procedure.

4. Accessing array elements is done by providing an index. Call the
   get_sys_index function to retrieve the indexes of the selected
   satellite systems, for example:
   
   i_G = get_sys_index('G')
   i_J = get_sys_index('J')

   Call the get_obs_index function from the obs_rinex3_indexes_mod.f90
   module to retrieve the indexes of the selected observation types,
   for example:

   i_g_l1c = get_obs_index('G', 'L1C', h%sys_num_obs_types)
   i_j_l1c = get_obs_index('J', 'L1C', h%sys_num_obs_types)

5. Read the epoch record using the read_next_epoch_record procedure.

6. Use the retrieved indexes to extract data from the epoch
   record. For example, for an epoch record named epr:

   associate (A => epr%sats_obs)
     do i_prn = 1, A(i_G)%n_prns
       g_l1c_val = A(i_G)%sys_sats_obs(i_g_l1c, i_prn)
     end do
     do i_prn = 1, A(i_J)%n_prns
       j_l1c_val = A(i_J)%sys_sats_obs(i_j_l1c, i_prn)
     end do
   end associate

FORMAT RINEX 3.x

Plik RINEX 3.x składa się z sekcji nagłówka i sekcji danych. Sekcja
nagłówka nazywana jest nagłówkiem, zaś sekcja danych ciałem.

			---------------------
			|                   |
 			|  SEKCJA NAGŁÓWKA  |
			|                   |
			---------------------
			|                   |
			|                   |
			|                   |
			|   SEKCJA DANYCH   |
			|                   |
			|                   |
			|                   |
			---------------------
				   
Nagłówek składa się z rekordów oznaczonych etykietami np. RINEX
VERSION / TYPE, PGM / RUN BY / DATE itd.

			---------------------
			|          ETYKIETA |
 			|          ETYKIETA |
			|          ETYKIETA |
			---------------------

Ciało składa się z rekordów danych albo inaczej rekordów epok, które
zawierają dane obserwacyjne.

			---------------------
			| REKORD EPOKI      |
			| REKORD EPOKI      |
			| REKORD EPOKI      |
			| REKORD EPOKI      |
			| REKORD EPOKI      |
			| REKORD EPOKI      |
			| REKORD EPOKI      |
			---------------------

Ważne: Dla odczytania danych obserwacyjnych z rekordów epok kluczowe jest
odczytanie linii z etykietami SYS / # / OBS TYPES z nagłówka pliku.


JAK MODUŁU UŻYWAĆ W KODZIE

Ogólny schemat odczytu pliku RINEX:

1. Dodaj instrukcję "use obs_rinex3" na początku swojego programu.

2. Najpierw należy odczytać nagłówek pliku procedurą read_header.

3. Zaalokować pamięć na dowolny rekord epoki procedurą
   allocate_epoch_record_buffer.

4. Dostęp do elementów tablic następuje przez podanie indeksu.  Przy
   pomocy funkcji get_sys_index należy pobrać indeksy wybranych
   systemów satelitarnych np.
   
   i_G = get_sys_index('G')
   i_J = get_sys_index('J')

   Przy pomocy funkcji get_obs_index pobrać indeksy wybranych typów
   obserwacji np.

   i_g_l1c = get_obs_index('G', 'L1C', h%sys_num_obs_types)
   i_j_l1c = get_obs_index('J', 'L1C', h%sys_num_obs_types)

5. Odczytać rekord epoki przy pomocy procedury read_next_epoch_record.

6. Przy pomocy posiadanych indeksów wybrać dane z rekordu epoki np.
   dla rekordu opoki epr
   
   associate (A => epr%sats_obs)
     do i_prn = 1, A(i_G)%n_prns
       g_l1c_val = A(i_G)%sys_sats_obs(i_g_l1c, i_prn)
     end do
     do i_prn = 1, A(i_J)%n_prns
       j_l1c_val = A(i_J)%sys_sats_obs(i_j_l1c, i_prn)
     end do
   end associate
